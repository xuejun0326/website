<a id="project-overview"></a>
## 二、项目说明

该仓库是一个面向操作系统比赛评测场景的 Linux 兼容内核，基于 ArceOS 运行时构建，以外部应用形式存在。整体架构定位为实验型/比赛专用型，而非完整的 Linux 兼容型或教学型。它通过 TestGroup/TestPlan 抽象组织多测试组顺序执行，以 Thread/CurrentThread 单核协作式调度（任务主动让出处理器后才发生切换的调度方式）为核心，在 ArceOS 的 axhal/axmm 等抽象之上实现了 Linux 系统调用（用户程序请求内核服务的受控入口）、内存管理、文件系统、信号、IPC（进程间通信，指不同进程交换数据和同步状态的机制）和网络等子系统。主要特点是：其一，针对比赛评测盘（musl/glibc（GNU C 标准库，向应用程序提供常用的 C 和 POSIX 接口））做了大量二进制补丁和私有 syscall 扩展（如 VOS 私有 musl shim），体现了对评测场景的深度定制；其二，采用单核协作式调度和 UnsafeCell 手动 Sync 的免锁设计，在单核假设下简化了并发控制，但限制了多核扩展；其三，文件系统采用只读 ext4（Linux 常用的第四代扩展文件系统） + 可写 ramfs 覆盖层的组合器设计，将设备节点直接建模为 VFS（虚拟文件系统，为不同文件系统提供统一接口）节点，统一了文件与设备访问路径。
