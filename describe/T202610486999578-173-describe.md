<a id="project-overview"></a>
## 二、项目说明

该仓库是 arceos-starry 家族中一个面向 LoongArch64（龙芯使用的 64 位指令集架构）平台的 Linux 兼容型内核，以 ArceOS 为底座，通过大量定制补丁和内核层扩展，实现了约 257 个系统调用（用户程序请求内核服务的受控入口），覆盖文件、进程、内存、信号、IPC（进程间通信，指不同进程交换数据和同步状态的机制）、网络等子系统。整体架构定位为实验型/教学型，而非完整 Linux 兼容型：它追求系统调用广度和 Linux 语义的近似，但在许多关键路径上采用简化或 stub 实现。主要特点：一是通过 `enum_dispatch` 和 `Backend` 枚举统一了四种内存映射后端（Linear/Cow（写时复制，多个执行单元先共享内存页，写入时再复制）/Shared/File），并引入全局帧引用计数表实现 COW 语义，这在 ArceOS 基线中并不存在；二是文件系统以 `FileLike` trait（Rust 用于声明一组接口能力的语言机制）统一了文件、socket、epoll、fanotify 等所有可被 fd 引用的对象，并通过 `downcast_arc` 实现运行时类型转换，大幅扩展了 fd 抽象范围；三是网络模块用自研 `Router` 替代 smoltcp 的 `Interface`，实现多网卡路由和 SYN 嗅探，体现了对 ArceOS 网络栈的深度改造。系统调用覆盖：257 项系统调用中，约 40% 是 stub 或简化实现，fork/execve/futex（快速用户空间互斥量，内核为用户态同步提供的等待与唤醒机制）路径存在非空实现，但 rseq、cacheflush 等为 no-op，消息队列阻塞语义缺失。
